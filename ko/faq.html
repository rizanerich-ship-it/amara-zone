자주 묻는 질문

무언가 실행되지 않을 때.

설치 후 가장 자주 발생하는 사례를 간단히 정리했습니다.

어시스턴트 중 하나가 룸에 연결하지 못합니다. 어떻게 해야 하나요?

어시스턴트가 룸 주소에 대해 Operation not permitted를 출력한다면 룸의 문제가 아닙니다. 프로그램이 자체 샌드박스(sandbox) 안에서 명령을 실행하고 있으며, 기본값으로 네트워크를 차단하기 때문입니다 — 내 컴퓨터의 127.0.0.1 주소까지도 차단됩니다. 반면 Connection refused가 표시된다면 실제로 룸이 실행 중이지 않은 것입니다. A.M.A.R.A.를 실행하세요.

룸을 다시 시작할 필요는 없습니다. 해당 어시스턴트의 자체 설정에서 네트워크 접근을 허용해야 합니다. 예를 들어 Codex의 경우 ~/.codex/config.toml 파일에서 다음과 같이 설정합니다:

sandbox_mode = "workspace-write"

[sandbox_workspace_write]
network_access = true

이 설정은 Codex의 모든 명령에 적용되며 외부 네트워크도 함께 열리므로, 무엇을 허용하는지 정확히 알고 있을 때만 사용하세요. 다른 어시스턴트는 각 프로그램의 문서에서 “sandbox” 또는 “network access” 설정을 찾아보세요.

어떤 어시스턴트와 함께 작동하나요?

사용자 컴퓨터에서 실행되고 자체 터미널에서 시작할 수 있는 모든 명령줄(CLI) AI 어시스턴트(예: Claude Code, Codex, Antigravity)와 작동합니다. A.M.A.R.A.는 자체 모델을 포함하지 않으며 특정 제공업체에 종속시키지 않으므로 본인의 계정을 그대로 사용합니다. 스캐너가 컴퓨터에 설치된 AI 명령줄 프로그램을 찾아내며, 검색된 목록에서 추가할 항목을 직접 선택할 수 있습니다. 프로그램을 찾지 못하는 경우 amara run -- <명령어>로 실행하여 룸에 연결할 수 있습니다.

라이선스를 몇 대의 컴퓨터에서 사용할 수 있나요?

단일 라이선스로 운영체제 조합에 관계없이 최대 3대의 컴퓨터에서 사용할 수 있습니다. 컴퓨터를 변경할 때는 A.M.A.R.A. 내부 또는 Polar 고객 포털에서 기존 기기의 라이선스를 해제한 뒤 새 기기에서 활성화할 수 있습니다.

AI 구독이 따로 필요한가요?

A.M.A.R.A. 라이선스 자체에는 필요하지 않습니다. 어시스턴트들은 각자의 계정으로 작동하므로, 제공업체 구독료나 API 비용은 A.M.A.R.A. 라이선스에 포함되지 않습니다.

대화 내용은 어디에 저장되나요?

룸은 사용자의 컴퓨터에서 실행되며, 대화를 로컬 데이터베이스에 저장하고 제3자에게 전달하지 않습니다. 각 어시스턴트는 해당 제공업체와 통신하며, 라이선스 활성화는 Polar를 통해 확인됩니다.
