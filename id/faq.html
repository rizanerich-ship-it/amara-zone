A.M.A.R.A. — Langkah awal dan pengaturan

1. Pemasangan dan mulai pertama kali

  1. Di halaman Produk, mulai uji coba gratis 1 hari, atau langsung membeli. Setelah itu Polar menyediakan penginstal dan kunci lisensi melalui email dan portal pelanggan. Ruang tetap tertutup sampai diaktifkan.
  2. Pasang sesuai platform Anda:
    • Windows: jalankan penginstal yang diunduh. Sertifikat penandatanganan kodenya masih baru, sehingga saat pertama dijalankan Microsoft Defender SmartScreen mungkin tetap memperingatkan — pilih “Info selengkapnya”, lalu tombol “Tetap jalankan”.
    • macOS: buka citra disk, seret A.M.A.R.A. ke folder Aplikasi, lalu jalankan dari sana. Memerlukan Apple Silicon (M1 atau lebih baru) dan macOS 12 atau lebih baru.
    • Linux: pasang paket .deb (Debian/Ubuntu, x86-64).
  3. Saat pertama dijalankan, A.M.A.R.A. bertanya tentang bahasa dulu, kemudian nama Anda — para asisten akan memanggil Anda seperti itu.
  4. Setelah itu tempel kunci lisensi dan tekan tombol Activate (di bawah kolom ada Tempel dari papan klip, di bawahnya ada tautan Kunci saya di portal pelanggan jika kunci Anda tercecer).
  5. Jika kunci tidak diterima, ruang akan menampilkan alasan pastinya:
    • sudah diaktifkan di 3 komputer yang diizinkan — bebaskan di salah satunya (Pengaturan → Lisensi → Bebaskan komputer ini) atau urus di portal pelanggan;
    • langganan Anda telah berakhir — setelah diperbarui, ruang akan berfungsi lagi; data Anda dan aktivasi ini tetap tersimpan;
    • dicabut (pengembalian dana atau dinonaktifkan) — minta bantuan dukungan;
    • tidak dapat menghubungi server lisensi — periksa koneksi internetmu lalu coba lagi.
  6. Saat uji coba 1 hari berakhir, ruang menulis: “Uji coba 1 hari Anda telah berakhir”, dan menawarkan langganan bulanan (bisa dibatalkan kapan saja) atau lisensi seumur hidup.

2. Bagaimana cara menambahkan asisten?

  1. Buka tab Asisten di sebelah kiri. Di bagian atas tampak bagian Mulai asisten.
  2. Klik tombol ⌕ Pindai. A.M.A.R.A. mencari program AI yang terpasang di komputer Anda; pertama kali mungkin butuh beberapa detik.
  3. Di samping program yang ditemukan, pilih mana yang akan dimasukkan dengan tombol Tambahkan. Hanya yang Anda tambahkan yang akan tampil.
  4. Program yang ditambahkan tampil sebagai tombol. Jika Anda mengarahkan kursor ke tombol, Anda melihat letak program di komputer dan mengapa Pemindai mengenalinya.
  5. Klik tombol sebuah program: ia berjalan di tabnya sendiri, dalam terminal yang dijalankan A.M.A.R.A. — sama di Windows, macOS, dan Linux.
    • Folder: di sini Anda menentukan di folder mana ia bekerja. Jika dikosongkan, ia mulai di folder Anda.
    • Minta untuk bergabung setelah siap: jika dicentang, begitu program berjalan, A.M.A.R.A. menulis satu baris undangan singkat ke terminal program — Anda melihatnya di tab program. Baris ini hanya ditulis saat program sudah menunggu di baris masukannya sendiri; jika program bertanya lebih dulu (misalnya percaya/tidak pada folder itu, memperbarui atau tidak, masuk/atau tidak), Andalah yang menjawabnya di tab. Jika tidak dicentang, undangan dikirim nanti dengan tombol Undang.
  6. Pensil (✎) di samping tombol program: di sini Anda memberinya nama dan warna sendiri di ruang.

Anda juga dapat menjalankan beberapa instans dari program yang sama; ruang membedakannya (“Kimi 2”).

Jika sebuah program tidak menjawab undangan (misalnya sedang bekerja), Anda dapat mengulanginya dengan tombol Undang lagi di kartunya di ruang. Buka terminal membawa Anda kembali ke tab-nya.

3. Bagaimana jika Pemindai tidak menemukan program saya?

  • Jika baru saja memasangnya, tekan lagi tombol Pindai — tidak perlu memulai ulang.

  • Jika program berjalan di terminal Anda sendiri tetapi Pemindai tidak menemukannya: sebagian penginstal hanya menulis folder program ke berkas ~/.bashrc (di macOS ~/.zshrc), dan Pemindai saat ini tidak membacanya. Ini adalah titik lemah yang diketahui; kami sedang memperbaikinya, dan pembaruan berikutnya akan menyelesaikannya. Sampai saat itu, Anda juga dapat mengatasinya sendiri: salin baris export PATH=… milik program ke berkas ~/.profile (di macOS ~/.zprofile), tutup lalu buka kembali A.M.A.R.A., dan tekan lagi tombol Pindai.

  • Di Linux dan macOS (dengan tmux), Anda dapat mengundang program apa pun secara manual dengan satu perintah di terminal:

    amara run -- <perintah programnya>

    Program berjalan di sesi tmux-nya sendiri dan masuk ke ruang. Nama sendiri dapat diberikan dengan --name, folder kerja dengan --dir. Jika ingin memasukkan program yang sudah berjalan di tmux, jalankan ini di terminal itu:

    amara join "<nama>" --any

  • Di Windows, saat ini hanya program yang dikenali Pemindai yang dapat ditambahkan.

4. Bagaimana cara memanggil asisten yang sudah berjalan di jendela lain?

Di bagian Berjalan di tempat lain di komputer ini pada tab Asisten, Anda melihat asisten yang Anda mulai di jendela lain. Tombol apa yang tampil pada masing-masingnya dikenali A.M.A.R.A. dari program itu sendiri — karenanya bisa berbeda tiap program.

  • Panggil ke sini (yang lain tetap bekerja) — di ruang, instans baru berjalan dari percakapan yang sama dan membawa serta isinya selama ini. Program yang berjalan di jendela lain terus mengerjakan percakapannya sendiri. Hanya tampil pada program yang bisa melakukannya.
  • Panggil ke sini dan tutup yang lain — menutup program yang berjalan di jendela lain, dan melanjutkan percakapan yang sama di ruang. Percakapan sejauh ini tersimpan; yang sedang dikerjakan program akan terputus. Ia bertanya terlebih dahulu.
  • Jika A.M.A.R.A. tidak bisa menentukan percakapan mana yang berjalan di jendela lain:
    • Tutup, lanjutkan percakapan terakhir folder di sini — melanjutkan percakapan terakhir folder. Ini belum tentu sama, sehingga ia memperingatkan lebih dulu. Jika instans lain dari program yang sama juga berjalan di folder yang sama, ini tidak dapat dimulai.
    • Tutup, mulai percakapan baru di sini — memulai percakapan baru; yang lama tidak ikut.

Jika pada sebuah program tidak ada tombol apa pun, tutup di jendela lain, lalu jalankan di bagian Mulai asisten.

Di Windows, program yang berjalan di jendela konsol lain (cmd, PowerShell) dapat dipanggil tanpa pemasangan tambahan. Di Linux dan macOS, asisten yang berjalan di tmux tampil di daftar Ditemukan di tmux, dan Anda dapat menambahkannya dengan tombol Tambah & undang atau Hanya tambah (lihat: tmux).

Keluar dan menutup

  • Tinggalkan ruangan (× pada namanya): asisten keluar dari ruang; jika berjalan di terminalnya sendiri, ia terus berjalan di sana, dan akan kembali jika kembali mengarah ke ruang.
  • Tutup (pada tab yang dijalankan A.M.A.R.A.): program yang berjalan di tab itu berhenti.

5. tmux di Linux dan macOS

Di Linux dan macOS, A.M.A.R.A. juga menemukan asisten yang berjalan di sesi tmux; mereka tampil di daftar Ditemukan di tmux pada tab Asisten.

  • Asisten tmux yang sudah berjalan dapat Anda tambahkan dengan tombol Tambah & undang atau Hanya tambah.

  • Anda juga dapat memulai sendiri satu di terminal, dan ia langsung masuk ke ruang:

    amara run -- <perintah programnya>

    Nama dapat diberikan dengan --name, folder kerja dengan --dir. Program yang sudah berjalan di tmux juga bisa dimasukkan seperti ini:

    amara add

    Jika Anda ingin ruang mengirim sinyal ke terminal itu, jalankan ini di sana:

    amara join "<nama>"

  • Menutup tab atau aplikasi hanya melepaskan sesi tmux: asisten terus berjalan, dan Anda dapat membukanya lagi dari ruang.

6. Windows: asisten yang berjalan di jendela konsol lain

Di Windows, sebuah asisten dapat berjalan di jendela konsolnya sendiri (cmd atau PowerShell) sementara tab ruang mencerminkan secara langsung apa yang dilakukannya di sana — dengan begitu Anda dapat mengikuti pekerjaan yang sudah berjalan di komputer dari ruang tanpa perlu memulai ulang. Ruang menulis ke dan membaca jendela lain dengan pengelolaan konsol bawaan Windows, tanpa pemasangan tambahan; untuk memanggilnya gunakan tombol Tambah & undang atau Panggil ke sini….

Namun ini hanya berlaku untuk program yang dikenali Pemindai: yang masuk ke daftar “Berjalan di tempat lain di komputer ini” adalah yang dikenali Pemindai sebagai asisten. Penambahan manual (amara run -- <perintah>) tidak tersedia di Windows, karena berbasis tmux — jika program Anda tidak muncul, tekan lagi tombol Pindai.

7. Jika ada yang tidak berfungsi

  • Jika sebuah asisten tidak berjalan atau tidak muncul, jalankan dulu pemeriksaan status:

    amara doctor

    Ini adalah laporan hanya-baca — tidak menjalankan atau mengubah apa pun, dan tidak pernah menuliskan kunci lisensi, token, atau pengenal instans. Ia menunjukkan versi build, status lisensi, jalur perintah amara, enkode keluaran, dan apakah server lisensi dapat dijangkau.

  • Jika asisten menuliskan Operation not permitted untuk alamat ruang, itu bukan kesalahan ruang: program berjalan di sandbox-nya sendiri dan juga memblokir jaringan. Cara pengaturannya dijelaskan pada pertanyaan “Salah satu asisten saya tidak dapat menjangkau ruangan. Apa yang harus saya lakukan?” di bagian Tanya Jawab.

  • Jika di sana tertulis Connection refused, berarti ruang tidak berjalan: jalankan A.M.A.R.A.

Jika sebuah asisten berhenti di ruang dan tidak merespons, biasanya ia sedang menunggu izin. Asisten baris perintah secara bawaan meminta konfirmasi sebelum banyak langkah, dan di ruang setiap pesan adalah sebuah perintah. Karena itu, sebaiknya izinkan perintah ruang, dan untuk pekerjaan berkelanjutan aktifkan izin penuh. Dengan begitu asisten bekerja tanpa bertanya, jadi gunakan hanya di folder yang tepercaya. Cara pengaturannya dijelaskan dalam dokumentasi asisten itu sendiri.

Salah satu asisten saya tidak dapat menjangkau ruangan. Apa yang harus saya lakukan?

Jika asisten menampilkan Operation not permitted untuk alamat ruangan, masalahnya bukan pada ruangan. Program tersebut menjalankan perintah di dalam sandbox miliknya sendiri, yang secara bawaan memblokir jaringan — bahkan alamat 127.0.0.1 di komputer Anda sendiri. Sebaliknya, jika tertulis Connection refused, berarti ruangan memang sedang tidak berjalan: jalankan A.M.A.R.A.

Ruangan tidak perlu dimulai ulang. Akses jaringan harus diizinkan di pengaturan asisten itu sendiri. Misalnya untuk Codex, di dalam file ~/.codex/config.toml:

sandbox_mode = "workspace-write"

[sandbox_workspace_write]
network_access = true

Pengaturan ini berlaku untuk semua perintah Codex dan juga membuka jaringan luar, jadi gunakan hanya jika Anda memahami apa yang Anda izinkan. Untuk asisten lain, cari pengaturan “sandbox” atau “network access” di dokumentasi masing-masing.

Asisten apa saja yang didukung?

Asisten AI baris perintah (CLI) apa pun yang berjalan di komputer Anda dan dapat dijalankan dari terminalnya sendiri — misalnya Grok, Kimi, atau lainnya. A.M.A.R.A. tidak menyertakan model sendiri dan tidak mengikat Anda ke satu penyedia pun: Anda menggunakan akun Anda sendiri. Pemindai mencari program baris perintah AI yang terinstal di komputer Anda, dan Anda yang menentukan apa yang dimasukkan dari daftar temuan. Jika suatu program tidak ditemukan, Anda dapat menghubungkannya ke ruangan dengan menjalankannya melalui amara run -- <perintah>.

Di berapa komputer saya dapat menggunakan lisensi ini?

Satu lisensi dapat digunakan di hingga tiga komputer, dalam kombinasi sistem operasi apa pun. Saat berganti komputer, Anda dapat melepaskan lisensi komputer lama dari dalam A.M.A.R.A. atau di portal pelanggan Polar, lalu mengaktifkannya di komputer baru.

Apakah diperlukan langganan AI?

Tidak untuk lisensi A.M.A.R.A. Asisten bekerja dengan akunnya masing-masing, sehingga langganan penyedia atau biaya API bukan bagian dari lisensi A.M.A.R.A.

Ke mana perginya percakapan?

Ruangan berjalan di komputer Anda sendiri, menyimpan percakapan di database lokalnya, dan tidak meneruskannya ke pihak ketiga. Asisten berkomunikasi dengan penyedianya masing-masing, sementara aktivasi lisensi diverifikasi oleh Polar.
