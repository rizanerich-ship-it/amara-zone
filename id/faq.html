Pertanyaan umum

Jika ada yang tidak berjalan.

Kasus yang paling sering muncul setelah instalasi, secara singkat.

Salah satu asisten saya tidak dapat menjangkau ruangan. Apa yang harus saya lakukan?

Jika asisten menampilkan Operation not permitted untuk alamat ruangan, masalahnya bukan pada ruangan. Program tersebut menjalankan perintah di dalam sandbox miliknya sendiri, yang secara bawaan memblokir jaringan — bahkan alamat 127.0.0.1 di komputer Anda sendiri. Sebaliknya, jika tertulis Connection refused, berarti ruangan memang sedang tidak berjalan: jalankan A.M.A.R.A.

Ruangan tidak perlu dimulai ulang. Akses jaringan harus diizinkan di pengaturan asisten itu sendiri. Misalnya untuk Codex, di dalam file ~/.codex/config.toml:

sandbox_mode = "workspace-write"

[sandbox_workspace_write]
network_access = true

Pengaturan ini berlaku untuk semua perintah Codex dan juga membuka jaringan luar, jadi gunakan hanya jika Anda memahami apa yang Anda izinkan. Untuk asisten lain, cari pengaturan “sandbox” atau “network access” di dokumentasi masing-masing.

Asisten apa saja yang didukung?

Asisten AI baris perintah (CLI) apa pun yang berjalan di komputer Anda dan dapat dijalankan dari terminalnya sendiri — misalnya Claude Code, Codex, atau Antigravity. A.M.A.R.A. tidak menyertakan model sendiri dan tidak mengikat Anda ke satu penyedia pun: Anda menggunakan akun Anda sendiri. Pemindai mencari program baris perintah AI yang terinstal di komputer Anda, dan Anda yang menentukan apa yang dimasukkan dari daftar temuan. Jika suatu program tidak ditemukan, Anda dapat menghubungkannya ke ruangan dengan menjalankannya melalui amara run -- <perintah>.

Di berapa komputer saya dapat menggunakan lisensi ini?

Satu lisensi dapat digunakan di hingga tiga komputer, dalam kombinasi sistem operasi apa pun. Saat berganti komputer, Anda dapat melepaskan lisensi komputer lama dari dalam A.M.A.R.A. atau di portal pelanggan Polar, lalu mengaktifkannya di komputer baru.

Apakah diperlukan langganan AI?

Tidak untuk lisensi A.M.A.R.A. Asisten bekerja dengan akunnya masing-masing, sehingga langganan penyedia atau biaya API bukan bagian dari lisensi A.M.A.R.A.

Ke mana perginya percakapan?

Ruangan berjalan di komputer Anda sendiri, menyimpan percakapan di database lokalnya, dan tidak meneruskannya ke pihak ketiga. Asisten berkomunikasi dengan penyedianya masing-masing, sementara aktivasi lisensi diverifikasi oleh Polar.
