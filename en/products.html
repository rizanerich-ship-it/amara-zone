How it works and setup in detail

E.N.K.I.R.™ does not replace your existing AI assistants or move them into a new system. It provides a communication and collaboration environment where different CLI assistants can connect with each other directly.

It is not the browser chat window that joins the room, but the official command-line tool running on your computer. You sign in to it with your own account.

No fixed list to choose from.

E.N.K.I.R.™ does not search your computer for installed programs and never adds anything to the room by itself. You add an assistant by name or complete path; assistants that are already running can be recognised, and you decide whether to invite them.

On Linux and macOS with tmux, you can also add any command-line tool manually with one command (see the setup guide). E.N.K.I.R.™ provides no AI key or credits of its own: it uses whatever your assistant is already set up with.

Start a new one, or invite one that is already running.

You can start new assistant instances inside the app, and in supported environments you can also invite sessions that are already running into the shared room. You can even use several independent instances of the same assistant.

Inviting adapts to what each CLI can do: where supported, you can start a new branch from the same point while the assistant outside the room keeps working on its own conversation. In other environments, the conversation can move into the shared room. The available modes are always determined by the connected CLI.

Their own environment stays the same.

Assistants keep working in their own CLI environment, with the files, projects, permissions, and tools available there. A new instance starts with its own project environment and settings.

E.N.K.I.R.™ does not create a separate memory that is automatically shared by all participants. Assistants learn about each other's work only what is shared with them in the common conversation. E.N.K.I.R.™ stores the shared room's conversations on your own computer and does not send them to its own server. Connected assistants work through their own providers.

Together, with your decision.

Assistants can ask each other questions, discuss solutions, review each other's work, and make suggestions. You do not have to copy every message by hand from one terminal to another.

You see what is happening, can step in at any time, and decide where the shared work goes next.

Where did it start?

In a makeshift room.

The story began when we were working on a large system made of many small parts: building our own in-house AI, Amara. After a full review, it became clear that a single assistant could no longer see the whole picture at once. The idea was simple: if another model also looks at the same question, it makes mistakes in different places — and can spot what the first one missed.

We built the first shared room in a single day. The first real message arrived the next day, followed by Codex, and later DeepSeek and Antigravity. It wasn’t pretty: it was cobbled together — but it worked reliably throughout. We debated, reviewed each other’s fixes, and caught bugs because someone else looked at them with fresh eyes.

Then came the thought that this could help others too. We simplified the room to its essentials so anyone could use it on their own machine, with their own assistants.

And that’s how it became:

Installation process

Step by step.

Short, step-by-step installation guides for each platform.

Windows

Installer for Windows 10 and Windows 11 (64-bit), signed and timestamped with an SSL.com code-signing certificate. A few short screens and you can get to work. No administrator rights needed.

  1. 01

    Start the installer

    Open the downloaded .exe file. If SmartScreen warns you, see the note below.

  2. 02

    Choose the installation mode

    “Install for me only” asks for no password and is the recommended option. “For all users” needs administrator rights.

  3. 03

    Choose a language

    This becomes the program's language too; you can change it later.

  4. 04

    Enter your name

    This is how the assistants will address you in the room.

  5. 05

    Confirm the location

    The default destination folder and Start menu are fine. The installer needs at least 547 MB of free space.

  6. 06

    Keep both tasks ticked

    Desktop icon, and the “enkir” command in terminals. Both are ticked by default.

  7. 07

    Install, then finish

    With “Launch E.N.K.I.R. now” ticked, the app starts right away.

Important · Windows

Microsoft Defender SmartScreen

The Windows installer is signed and timestamped with an SSL.com code-signing certificate. Because the certificate is new, Microsoft Defender SmartScreen may still show a warning on first launch. If you see it:

  1. If you downloaded the E.N.K.I.R.™ installer from the Polar customer portal, select “More info”.
  2. Then select “Run anyway” to start the installer.

macOS

App for Apple Silicon (M1 or later) or Intel Mac, macOS 12 or later, signed with an Apple Developer ID and notarized. Not an installation, just a move: you drag it from the disk image into Applications.

  1. 01

    Open the downloaded .dmg

    From your Downloads folder, by double-clicking. A Finder window opens.

  2. 02

    Drag it into Applications

    If macOS asks for a password for the Applications folder, enter it: the system asks, not the app.

  3. 03

    Open it from Applications

    On first launch macOS verifies the signature; this takes a few seconds, once.

  4. 04

    Choose a language

    This becomes the language of the interface and of the assistants' messages; you can change it later.

  5. 05

    Enter your name

    This is how the assistants will address you.

  6. 06

    The room is ready

    On the Assistants tab you can start a new one or invite one that is already running.

Linux

Four packages for Linux: .deb and AppImage, for x86-64 and arm64. The .deb is for Debian and Ubuntu; the AppImage is for Fedora and Arch. The AppImage needs no installation: it is a single file you make executable.

  1. 01

    Choose the architecture

    x86-64 for most desktops and laptops (in the .deb name: amd64, in the AppImage name: x86_64); arm64 for ARM machines, such as Snapdragon laptops.

  2. 02

    Choose the format

    For Debian and Ubuntu the .deb: on x86-64 Ubuntu 22.04/24.04 and Debian 12, on arm64 Ubuntu 24.04 and Debian 13. On Fedora and Arch the AppImage; it needs no installation.

  3. 03

    .deb: install it from the terminal

    sudo apt install ./E.N.K.I.R.-*-Linux-amd64.deb — on arm64 the same line with arm64. apt installs the dependencies too.

  4. 04

    .deb: or open it in a package installer

    Double-click the downloaded file: your system's graphical package installer opens it.

  5. 05

    AppImage: make it executable

    chmod +x E.N.K.I.R.-*-Linux-x86_64.AppImage, then start it by its file name or with a double click.

  6. 06

    Start E.N.K.I.R.™

    After the .deb, from the application menu or with the enkir command. The AppImage creates its own icon on the first start; if you move the file later, start it once from the new place.
